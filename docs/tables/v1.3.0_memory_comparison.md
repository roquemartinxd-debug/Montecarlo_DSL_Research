# Resultados historicos v1.3.0: carga retenida estimada, RSS por proceso y fidelidad de cuantiles

> **Advertencia:** estas cifras pertenecen a la implementacion v1.3.0. No validan los cambios v1.3.1 de ventana de tareas y buffers limitados. La carga retenida es una estimacion de payload, no RSS. Las columnas RSS historicas representan suma de maximos por proceso, no pico simultaneo del arbol de procesos.

La version v1.3.1 limita la ventana multiproceso a `2 * worker_count` y los buffers pendientes a 64; la afirmacion de memoria acotada respecto a N requiere fijar tamano maximo de tarea, workers y ventana. Los resultados deben regenerarse antes de publicacion.
