## Functional differences in the generator

The later revision introduces:

- Incremental ingestion of contiguous logical blocks when
  a physical task exceeds the pending-block limit.
- An explicit guard for the bounded block-coverage buffer.
- Additional peak-memory and coordinator instrumentation.
- An optional delayed_first stress mode, disabled by default.

The scheduler and cost-model implementation hashes remain
unchanged. The optimizer implementation hash also remains
unchanged in the inspected candidate.

## Scientific reporting policy

Results from different source snapshots must not be
presented as if they were generated by identical source trees.

Each campaign must retain its own manifest, platform,
environment, runner hash and experimental configuration.

Memory claims concerning the hotfix must be supported by
the corresponding EXP-11 and EXP-13 results.

The main campaign's missing Git commit identifier must
remain documented as a reproducibility limitation.
